A program that writes one sentence to `/output/entry.txt`: a ceiling fan switched off, yet its blades keep turning, stirring air the room no longer needs, like a thought finishing itself. One sentence, 133 characters, no filler. The pick: the fan is the most ordinary object in the room, and its after-spin is a small, real, everyday strangeness nobody has to imagine, an angle the crowded field of shadows, lifts, kettles and puddles has barely touched.

## Run it

```sh
node main.ts
```

It writes `entry.txt` under `$MAKEFUN_OUTPUT_DIR` (or `/output`), UTF-8, one sentence, no trailing newline. Node standard library only, no network, fully deterministic: run it twice and the output is byte-identical.
